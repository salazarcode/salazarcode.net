🌐 legal.salazarcode.net ⭐ Proyecto Destacado

Legal RAG Venezuela

Asistente conversacional de inteligencia artificial y recuperación semántica de alta precisión especializado en la legislación venezolana. Elimina las alucinaciones de los LLMs mediante citas obligatorias del articulado legal en tiempo real.

.NET 8 C# Web API PostgreSQL 16 (pgvector HNSW) Ollama (nomic-embed-text) Angular 18 Standalone Streaming SSE (TTFT < 1s) Microsoft Entra ID (Azure AD) Docker Compose (4 Microservicios)
⚖️
Fundamentación Estricta: Consulta directa de la Constitución de 1999, Código Civil, Ley de Seguros y leyes financieras indexadas.
⚡
Búsqueda Vectorial HNSW: Recuperación semántica por distancia coseno en menos de 150 ms con embeddings calculados 100% en local.
💬
UI Conversacional Tipo ChatGPT: Diálogo continuo multi-turno con memoria de sesión, telemetría de latencia en vivo y selector de fuentes.
🛡️
Seguridad Anti-Inyecciones: Sanitización activa de prompts, rate limiting sliding window por IP y control de acceso OAuth 2.0 PKCE.

🌐 mapa.salazarcode.net Visualización Geoespacial

Mapa Interactivo de Venezuela

Visualizador web cartográfico interactivo con navegación jerárquica multinivel (País ➔ Estado ➔ Municipio ➔ Parroquia). Renderizado vectorial de alta definición sin pérdida de resolución al hacer zoom.

D3.js (d3-geo & d3-zoom) GeoJSON Estandarizado (OCHA / ONU) Vite Singlefile SVG Dinámico Tailwind CSS Docker Nginx
📍
Cobertura Total: 25 entidades federales (incluyendo Dependencias Federales), 335 municipios y 1.136 parroquias, con inclusión de la Guayana Esequiba.
🗺️
Drill-down Progresivo: Transición visual fluida entre niveles administrativos con cálculo de centroides y bounding boxes geográficos.
🔄
Sincronización Bidireccional: Hover simultáneo entre los polígonos vectoriales del mapa y la lista lateral de entidades.
📦
Zero-Latency Bundle: Todo el mapa y los datos se compilan en un único archivo autónomo de carga inmediata.
